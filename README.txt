TRICIA QUACH PORTFOLIO — VS CODE PROJECT

1. Unzip the folder.
2. Open VS Code > File > Open Folder > select tricia-portfolio.
3. Open index.html with Live Server, or double-click index.html to preview.
4. detail.html is the second page and shares css/style.css.
5. The assets/*.svg files are intentionally labelled placeholders, NOT real photos or an official university logo. Replace them with your own images and update the src paths in index.html.
6. Replace LinkedIn/GitHub placeholder URLs and empty mailto: links with your real contact links before publishing.
7. Both pages use a responsive layout; test at 1440px and 390px.
